# 小安界面素材

首页插画：`comfort-illustration.png`。头像：`xiaoan-avatar.png`。
这两张图片是根据用户提供的 Figma 截图生成的参考素材，并非 Figma 原始导出文件。

替换同名文件即可更新显示；如需更改名称或使用 WebP/SVG，在 `config/brand-assets.ts` 中更新路径。
头像由首页标志、聊天标题、欢迎区和 AI 消息共同使用。建议使用正方形图片；原图若已经裁切到头像边缘，将配置里的 `avatarSize` 改为 `cover`。目前参考头像周围有留白，所以使用 `170%` 居中显示。
首页插画建议使用约 4:3 的图片，背景色为 `#FBF9F6` 或透明背景。页面会自动适配桌面和手机宽度。
